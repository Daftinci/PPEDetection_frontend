## About

## This app mainly will detect PPE rules violation that create automatic monthly/daily reporting and interactive dashboard

## Features

- [x] Detect PPE rules violation -[x] Person -[x] No Coverall -[x] No Hardhat
- [x] Detect Fire & Smoke
- [x] PPE Dashboard violation
- [x] Auto Reporting
  - [x] Alert message via telegram
  - [x] Monthly/Daily Reporting

---

## How it works

The project is divided into two parts:

1. Models (Another Repo)
2. Frontend (this repo)

Models are containing machine learning models to detect PPE, fire & smoke
